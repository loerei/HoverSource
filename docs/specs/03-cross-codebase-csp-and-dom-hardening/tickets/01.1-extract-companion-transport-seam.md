- [x] 1. **Create HTTP-only `companionTransport` module**:
  - **Files:** **[NEW]** [companionTransport.ts](file:///d:/Projects/HoverSource/packages/overlay-core/src/companionTransport.ts)
  - Export `getCompanionBaseUrl(): string` and HTTP-only `companionRequestJson<T = any>(path: string, init?: { method?: string; headers?: Record<string, string>; body?: string; timeoutMs?: number; signal?: AbortSignal }): Promise<T>`:
    - Preserve exact proxy vs local port routing (`"/hoversource"` when `globalThis.__HOVERSOURCE_PROXY__` is set, otherwise `http://127.0.0.1:${port}`).
    - Clamp/validate `timeoutMs`: `Number.isFinite(init?.timeoutMs) && init!.timeoutMs! > 0 ? init!.timeoutMs! : 5000`.
    - Support optional `signal?: AbortSignal`:
      - At the start of `companionRequestJson` (before timer setup, listener registration, or `fetch`), check `if (init?.signal?.aborted)` and reject immediately with `init.signal.reason instanceof Error ? init.signal.reason : new Error(\`Companion request \${method} \${path} aborted\`)`.
      - Compose caller `init?.signal` with `timeoutController: AbortController` using a named `onAbort` handler attached via `init.signal.addEventListener("abort", onAbort, { once: true })`.
      - Execute both the `!res.ok` status check and `await res.json()` inside `fetchPromise` with late-rejection suppression:
        ```ts
        const fetchPromise = Promise.resolve().then(async () => {
          const res = await fetch(url, {
            method,
            headers: init?.headers,
            body: init?.body,
            signal: timeoutController.signal,
          });
          if (!res.ok) {
            throw new Error(`Companion HTTP ${method} ${path} failed with status ${res.status}`);
          }
          return (await res.json()) as T;
        });
        fetchPromise.catch(() => {});
        ```
      - Race `fetchPromise` against an `abortPromise` bound to `timeoutController.signal`'s `"abort"` event (rejecting with `timeoutController.signal.reason` on timeout `{ cause: err }` or caller abort), and in `finally` clear the timeout timer and unconditionally remove `"abort"` listeners from both `init?.signal` and `timeoutController.signal` (preventing deadlocks when `fetch` mocks ignore `init.signal` or hang in `res.json()`, and preventing `UnhandledPromiseRejection` when real `fetch` rejects after timeout/abort).
